## S1J1 — Comprendre un LLM
   - Définition en 1 phrase : un systeme de prédiction du prochain token. Token: unité atomique manipulée par le LLM ( 3-4 caractere, parfois un mot entier, parfois un fragment.. esemple: manger= 1 token, démoduler= 3 token). Probabilité = Ce que le LLM calcule pour chaque token candidat. Le LLM choisit le prochain token selon ces probabilités. LLM se compose de 2 fichiers : fichier parametres ( 140 gb le poids du modele le résultat de l'entrainement / fichier run.c ( 500 lignes de code C ) : programme qui execute le modele. 
   - Analogie (perso) : comme au clavier quand t'ecrit un mot il prédit le mot qui suit parmis plusieurs choix.
